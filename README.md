
# Além do Jogo

O **Além do Jogo** é um projeto acadêmico desenvolvido com o objetivo de apresentar informações, histórias, curiosidades e características de diferentes jogos eletrônicos.

O site reúne conteúdos sobre jogos que marcaram a indústria dos videogames, explorando suas histórias, personagens, mundos, versões e aspectos importantes.

## 🎮 Jogos apresentados

- **The Legend of Zelda:** Ocarina of Time
- **Grand Theft Auto VI**
- **Minecraft**
- **Genshin Impact**

## 💻 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## 🚀 Como executar

1. Clone o repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Abra o arquivo `index.html` utilizando a extensão Live Server ou outro servidor local.
4. Navegue pelo site e acesse as páginas dos jogos.

## 📚 Objetivo acadêmico

Este projeto busca desenvolver conhecimentos práticos em desenvolvimento web, estruturação de páginas, estilização com CSS, organização de arquivos e trabalho colaborativo utilizando Git e GitHub.
